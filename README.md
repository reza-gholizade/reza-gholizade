## 🚀 Featured Engineering Work

### [k8s-mcp-server](https://github.com/reza-gholizade/k8s-mcp-server)

A Go-based **Kubernetes Model Context Protocol server** for AI-assisted cluster operations.

- Kubernetes resource discovery, inspection, logs, events, and metrics
- Kubernetes + Helm tooling through MCP
- `stdio`, SSE, and Streamable HTTP transports
- read-only mode for safer operations
- multi-context Kubernetes support
- bearer authentication and explicit browser-origin controls for HTTP transports
- secure-by-default container execution

### ARVIX platform engineering

Architecting a production-oriented control plane around **Go, PostgreSQL, Incus, Cloudflare Tunnel, Kubernetes, observability, and durable asynchronous workflows**.

Recent engineering work includes:

- multi-worker coordination and PostgreSQL-backed leadership
- stale-worker fencing and crash-safe operations
- durable transactional outbox and at-least-once event delivery
- generation-safe instance rebuild / resize workflows
- reconciliation and runtime convergence
- ownership-safe Cloudflare exposure management
- rate limiting, mutation gates, health/readiness, backups, and production runbooks

### [awesome-mcp-servers](https://github.com/reza-gholizade/awesome-mcp-servers)

A curated MCP server collection built around the growing ecosystem of **AI agents + infrastructure tooling**.
